The network
The computer is on the network through its network card, lan0, which asks the network for an address (DHCP) when the system starts.

WebExplorer (on the desktop, and in Connections) shows web pages: their text, headings, lists and links. Click a link to follow it; Back, Forward, Reload and Home are along the top, the address next to them (Ctrl+L to type one, Enter to go). The status line shows where a link goes. Forms work: click a field and type (Tab: the next field), then Enter or the form's button sends it - the home page has a Wikipedia search. Pictures come in after the page. Pages look as their style sheets say, as far as WebExplorer goes: their colours and background, what's hidden (menus that open with a click stay shut), what's bold, centred or monospaced. Sites' cookies are kept, so logins and choices last; the ones with a date stay for the next time (in \OS2\cookies.txt), and about:cookies lists them, with a link to throw them all away. Scripts don't run, so pages that need them (or a picture puzzle to prove you're a person) won't work. Secure (https) pages come encrypted, but their certificates aren't checked.

The Connections folder on the desktop:
  WebExplorer      the web
  TCP/IP Status    lan0's address, gateway and name servers (Refresh asks again)
  Ping             is a host there? (four echo requests)
  Telnet           a session on another computer

In a Command Prompt:
  IFCONFIG                 the same as TCP/IP Status
  PING host [count]        echo requests, by name or address
  HOST name                looks a name up
  wget -O file URL         fetches a file (http or https)
  nslookup name            looks a name up, the long way
  nc host port             a TCP connection; nc -l -p port waits for one

Programs on the system - the UNIXROOT ones, and your own - can use the network as on Unix: TCP and UDP sockets over IPv4. The name servers are the ones DHCP gave, unless there's a \ETC\RESOLV.CONF of your own on drive D.

Under QEMU the computer is 10.0.2.15 and the Mac (or PC) it runs on is 10.0.2.2.
