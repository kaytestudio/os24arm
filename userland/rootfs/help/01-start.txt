Getting started
Welcome to OS/2 Warp for ARM64.

The screen in front of you is the Workplace Shell: the desktop. Everything on it is an object - a folder, a drive, a program, a file - and you work with objects directly: double-click one to open it, right-click it for its menu, drag it to move it somewhere else.

Along the top is the WarpCenter. Its first button is the system menu (the same menu you get by right-clicking an empty part of the desktop); the others open the Window List, an OS/2 Command Prompt, the Drives folder and the Programs menu. The clock is on the right, and next to the buttons is the title of the window you're using.

Down the left side are the desktop's objects: OS/2 System (the system's folder), the Assistance Center (this help - F1 opens it too), Drives, Command Prompt, Drive D, Programs and Window List. Shut Down and the Shredder are at the bottom right.

When you're finished, double-click Shut Down (or type SHUTDOWN in a Command Prompt). Every program is closed, every drive is unmounted cleanly, and the computer is turned off.
