The System Editor
The System Editor edits text files. Double-click a text file in a folder to open it there; "System Editor" in OS/2 System starts with an empty one.

Type to write; the arrows, Home and End, Page Up and Page Down move around (Ctrl+Home and Ctrl+End: the start and the end of the file). Hold Shift while you move - or drag with the mouse - to select text. Enter starts a new line, indented like the one before.

  Ctrl+S        save
  Ctrl+X        cut what's selected
  Ctrl+C        copy it
  Ctrl+V        paste
  Ctrl+A        select everything
  F10           the menu bar

File > Save as saves under another name: type the whole name, with its drive and folders (D:\NOTES\TODO.TXT).

The title bar shows a * while there are changes that aren't saved; closing the window then asks whether to save them.

Lines end as on Unix (a new line only); tabs show as spaces up to the next multiple of eight.
